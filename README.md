# ECommerce-Customer-Behavior- Intern ID: CITS2712, Firdaus Khan
## Project Overview
This project focuses on analyzing customer purchasing behavior in an e-commerce business using Exploratory Data Analysis (EDA). The objective is to understand customer demographics, spending patterns, product preferences, and return behavior to generate actionable business insights.

---

## Business Problem

E-commerce companies collect large amounts of customer data, but identifying meaningful patterns can be challenging. This analysis helps answer questions such as:

- Which customer segments spend the most?
- Which product categories generate the highest revenue?
- Which cities contribute the most sales?
- Is there a relationship between customer income and purchase amount?
- Does customer satisfaction influence product returns?

The insights can help businesses improve marketing strategies, inventory management, and customer experience.

---

## Dataset Description

The dataset contains customer transaction information with the following columns:

| Column | Description |
|---------|-------------|
| CustomerID | Unique identifier for each customer |
| Age | Customer's age |
| Gender | Customer's gender |
| City | Customer's city |
| Income | Annual income of the customer |
| PurchaseAmount | Amount spent on the purchase |
| ProductCategory | Category of the purchased product |
| Satisfaction | Customer satisfaction rating (1–5) |
| Returned | Whether the product was returned (Yes/No) |
